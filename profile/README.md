# ICT Development Portfolio

웹서비스·API·서버 운영 중심의 개발 포트폴리오입니다. 기획부터 배포·운영까지 직접 맡은 프로젝트를 모았습니다.

## 재직 중 담당 업무

| 프로젝트 | 내용 | 기술 | 단계 |
|---|---|---|---|
| [MUSTSEM](https://github.com/ict-portfolio-2026/mustsem-case-study) | 기업용 Web3 인프라 서비스 웹사이트. 서버리스 API, 인증, 지갑 연동 | Next.js, TypeScript, Supabase Auth, Vercel | 운영 중 |
| [IP 담보 자동대출 PoC](https://github.com/ict-portfolio-2026/ip-loan-poc-case-study) | 특허 담보 대출 신청 → 평가 → 심사 → 토큰화 → 상환 시연 시스템 | Flask, SQLite, Solidity, Nginx | PoC |

회사 과제라 소스코드 대신 설계·구현을 정리한 문서를 공개합니다.
